## Title

Packet Proof | Nutrient DWS Trade-Document Exception Desk Demo

## Description

Packet Proof is an auditable exception desk for shipment-document review. Nutrient DWS provides the structured-document extraction path; Packet Proof deterministically reconciles the extracted evidence, catches cross-document mismatches, and keeps the release decision with a human.

This 2:57 demo uses three fictional trade documents and the repository's clearly labeled synthetic replay fixtures. It demonstrates a blocking 24-versus-22 quantity mismatch, source hashes, page-linked evidence, a stable audit hash, and the human-authority boundary. It does not claim the replay is a recorded live API call.

Nutrient DWS extracted structured JSON content from each source PDF; Packet Proof reconciled those extracted fields deterministically and reserved the release decision for a human.
